# 代码区

## 这里只写和 Cle2000 有关的东西

## Cle2000 唯一核心语法

**输出对象 := 模块名: 输入对象 :: 模块数据 ;**（记得最后要加 ;）

e.g.

```text
FLUX := FLU: SYS MACRO TRACK :: TYPE K ;
```

意思是：用 **FLU:** 模块，输入 **SYS MACRO TRACK**，数据段写 **TYPE K**，输出对象叫 **FLUX**。

模块必须先在文件开头声明：

```text
MODULE GEO: SYBILT: MAC: ASM: FLU: EDI: DELETE: END: ;
```

数据对象也必须先声明：

```text
LINKED_LIST MACRO ANGEO TRACK SYS FLUX EDITION ;
```

## CLE-2000 书写规则

1. 文件后缀：主文件 .x2m，过程文件 .c2m
2. 每行不能超过 132 字符，只有前 120 字符有效
3. * 或 ! 后面是注释
4. (* ... *) 之间是注释
5. 区分大小写
6. 空格是分隔符
7. 禁止 Tab
8. 对象名最多 12 字符
9. 每条模块调用最后要有 ;
10. 嵌入模块用 :::

## 关于 .x2m 文件

- 这个是个**纯文本输入文件**，用文本编辑器打开就行，或者和我一样用 *Notepad++*。
- 文件一般放在 DRAGON 的 Dragon 目录下。
[就是这里](../material/Dragon文件目录.PNG)
- 创建：打开 Ubuntu 终端，进入 Dragon 目录，用 nano 新建文件

```bash
nano 名字.x2m
```

- 保存：Ctrl + O ；退出：Ctrl + X。

> 这些是 Ubuntu 指令，详细请出门左转查看 Linux 指令怎么写。

- 运行要在 **Ubuntu 终端** 里用 DRAGON 的 **rdragon 命令**

```bash
./rdragon 名字.x2m
```

- 如果提示权限不够：

```bash
chmod +x rdragon
```

- 运行后会在当前目录生成输出文件，比如 *tcm01_min.lst*、*tcm01_min.out* 或者 .xsm 文件，取决于你的输入。

### 一、*宏观截面：直接输入* 这一段

字段速记：

- **NGRO 2**：2 个能群
- **NMIX 2**：2 种材料
- **MIX 1**：第 1 种材料
- **TOTAL**：总截面，每个能群一个值
- **SCAT**：散射矩阵。
- **NUSIGF**：νΣf
- **CHI**：裂变谱

#### 这段的作用

All in all：

**这段的作用是直接定义宏观截面库，不依赖外部微观库。输出的对象叫 MACRO，类型是 MACROLIB。**
定义材料，定义截面，具体这个材料代表什么，在 GEO 里面分配，这里只是定义材料库。

#### 逐行解释

`MACRO := MAC: ::`

- `MACRO`：输出数据结构的名字，你可以随便改，比如叫 MACLIB。名字最多 12 个字符。
- `:=`：赋值符号，表示把右边模块产生的结果存到左边。
- `MAC:`：调用的模块名，负责处理宏观截面。
- `::`：模块调用的数据段开始。后面所有内容都是 MAC: 模块的输入参数。

> 这一行整体意思是：创建一个名为 MACRO 的宏观截面库，输入数据从下一行开始。

`NGRO 2 NMIX 2 NIFI 1`

- `NGRO 2`：能群数 = 2。后面所有截面数据都要按 2 个能群给。
- `NMIX 2`：材料数 = 2。后面会定义 MIX 1 和 MIX 2。
- `NIFI 1`：每个材料的裂变谱数 = 1。通常一个材料只有一个裂变谱，这里写 1。

> 这一行是全局参数，告诉模块这个库有多大。

`READ INPUT`

- 表示截面数据直接从输入流读取，而不是从外部文件读。
- 因为你要手写宏观截面，所以必须写 READ INPUT。
- 如果从 GOXS 文件读，就会用 READ GOXSRN 之类。

> 如果用 GOXS 文件读的话，例子如下：

```text
MACRO := MAC: ::
NGRO 2 NMIX 2
READ GOXSRN goxs文件名
;
```

`MIX 1`

- 开始定义第 1 种材料。
- 后面跟的数据都属于材料 1，直到遇到下一个 MIX 或 ;。

`TOTAL 0.222222 0.833333`

- `TOTAL`：总截面 Σt。
- 后面两个数分别对应**第 1 群**和**第 2 群**。
- 第 1 群总截面 = 0.222222 cm⁻¹。
- 第 2 群总截面 = 0.833333 cm⁻¹。
- 注意顺序：先写第 1 群，再写第 2 群。DRAGON 默认能群从 1 到 NGRO，通常 1 是快群，NGRO 是热群。

`SCAT`

- 开始输入散射矩阵。
- 散射矩阵描述中子从某个源群散射到某个目标群的截面。
- 格式通常是：源群 目标群 截面值，可以写多行，自由格式。
- 下面几行就是散射数据。

```text
1 1
0.19222
```

- 这两行合起来表示：源群 1 → 目标群 1 的散射截面 = 0.19222 cm⁻¹。
- 因为自由格式，换行不影响，所以 1 1 0.19222 是同一个意思。
- 也就是说，第 1 群的中子散射后仍然留在第 1 群的截面是 0.19222 cm⁻¹。

`2 2 0.75333 0.02`

这一行包含两组信息：

1. `2 2 0.75333`：源群 2 → 目标群 2 的散射截面 = 0.75333 cm⁻¹。
2. `0.02`：紧跟在后面，通常表示源群 2 → 目标群 1 的散射截面 = 0.02 cm⁻¹。这是热群到快群的上散射。

为什么没有写目标群号？因为格式允许连续给值，默认按目标群顺序。这里也可以写成：

```text
2 2 0.75333
2 1 0.02
```

`NUSIGF`

- 开始输入 νΣf，即**中子产额**乘以**裂变截面**。
- 这是裂变源项。如果没有裂变，可以全写 0。

`0.0`

- 第 1 群的 νΣf = 0.0。
- 说明第 1 群（快群）不直接产生裂变中子，或者这个材料在这一群没有裂变。

`0.135 CHI 1.0 0.0`

- `0.135`：第 2 群的 νΣf = 0.135。
- `CHI`：开始输入裂变谱 χ。
- `1.0 0.0`：裂变谱的两个值：
  - 第 1 群 χ1 = 1.0
  - 第 2 群 χ2 = 0.0
- 意思是：裂变产生的中子全部进入第 1 群（快群），第 2 群没有。这是典型的两群裂变谱。

`MIX 2`

- 开始定义第 2 种材料。

`TOTAL 0.166667 1.111111`

- 材料 2 的总截面：
  - 第 1 群 = 0.166667
  - 第 2 群 = 1.111111

`SCAT`

- 开始输入材料 2 的散射矩阵。

```text
2 2
0.00015 0.126667 2 2 1.10111 0.04
```

- 这里和材料 1 的写法类似，但数字多了。自由格式下，可以拆成：
  - `2 2 0.00015`：源群 2 → 目标群 2 的截面 = 0.00015
  - `0.126667`：源群 2 → 目标群 1 的截面 = 0.126667
  - `2 2 1.10111`：又是一组源群 2 → 目标群 2 的截面 = 1.10111
  - `0.04`：源群 2 → 目标群 1 的截面 = 0.04
- 为什么有两组？这可能是因为材料 2 的散射数据分成了两部分（比如弹性散射和非弹性散射分别写），DRAGON 会把它们加起来。最终材料 2 的散射矩阵大致是：
  - 2→2：0.00015 + 1.10111 = 1.10126
  - 2→1：0.126667 + 0.04 = 0.166667
  - 1→1、1→2 未给，默认为 0。
- 注意：实际输入时最好写成清晰的多行，避免歧义。比如：

```text
SCAT
2 2 0.00015
2 1 0.126667
2 2 1.10111
2 1 0.04
```

`;`

- 整个 MAC: 模块的数据段结束。
- 分号表示模块调用结束。

> 总结：材料 1 有裂变，材料 2 没有裂变（因为没写 NUSIGF 和 CHI）。

---

如果要用微观库，不要用 MAC:，而是用 LIB:：

```text
LIBRARY := LIB: ::
NMIX 3 CTRA WIMS
MIXS LIB: WIMSD4 FIL: iaea
MIX 1 600.0
O16 = '6016' 4.61309E-2
U235 = '2235' 1.66078E-4 1
U238 = '8238' 2.28994E-2 1
;
```

后面加自屏：

```text
LIBRARY := SHI: LIBRARY TRACK ::
EDIT 0 NOLJ ;
```

然后写 ASM 段。

### 二、*几何：1D 圆柱，2 个径向区* 这一段

字段速记：

- **TUBE**：二维 / 一维环形（圆柱）几何模块，对应 DRAGON 的 TUBE 几何，1D 径向模型，轴向厚度默认为 1。
- **R+ REFL**：外边界条件，径向外侧 R + 为全反射边界。
- **RADIUS**：径向网格，定义各环形分界面半径。
- **MIX**：给每个径向环分配材料编号。
- **SPLITR**：径向跟踪细分参数，径向方向的子分割数。

#### 这段的作用

All in all：

**这段的作用是构建一维径向圆柱环形几何，输出对象叫 ANGEO，类型是 GEO 几何对象。**
定义几何形状、径向网格、边界条件、每个径向区域对应的材料号，后面 TRACK 跟踪模块会读取这个几何对象做射线跟踪。

#### 逐行解释

`ANGEO := GEO: ::`

- `ANGEO`：输出几何数据结构的名字，用户自定义，最多 12 字符。
- `:=`：赋值符号，把右侧模块产生的几何结果保存到左侧变量。
- `GEO:`：DRAGON 几何定义模块，专门用来输入几何卡片。
- `::`：模块输入数据段开始，后续所有行属于 GEO 模块输入。

> 整行含义：创建名为 ANGEO 的几何对象，几何输入从下一行开始。

`TUBE 2`

- `TUBE` 代表**环形（圆柱）几何**，在 DRAGON 中 TUBE 是二维 x-y 平面上同心圆环形几何；当没有 x/y 方向网格时退化为纯 1D 径向几何（本算例就是 1D 径向，轴向厚度固定为 1）。
- 数字 `2`：径向环的数量，本几何一共 2 个径向环形区域。

> 这里 TUBE 2：几何包含 2 个径向环形区。

`R+ REFL`

- 设置几何外边界条件。
- TUBE 几何边界命名：`R-` 是圆心内侧（r=0，几何内部，不能设置边界）；`R+` 是最外圈的径向外边界。
- `REFL` = Reflective，全反射边界条件，中子撞击边界完全反射回来，无泄漏。

> 含义：本环形几何最外侧径向边界使用反射边界。

`RADIUS 0.0 0.19653 1.0`

- `RADIUS`：径向半径网格关键字。
- 后面依次是径向分界面的半径值（单位 cm）。
- `0.0`：圆环内起点，圆心；
- `0.19653`：第 1 环与第 2 环的分界面半径；
- `1.0`：几何最外圈外半径，对应 R + 边界所在位置。

本几何两个径向环：

- 1 区：`0.0 ≤ r < 0.19653 cm`
- 2 区：`0.19653 ≤ r < 1.0 cm`

`MIX`

给每个径向环分配材料编号，顺序和径向环顺序一一对应，从内环向外环。

```text
MIX
1
2
```

- `MIX` 关键字开启材料分配；
- 第 1 环（内环 0-0.19653）分配 `MIX 1`；
- 第 2 环（外环 0.19653-1.0）分配 `MIX 2`。

> 材料编号必须和前面 MACRO 宏观截面库的 MIX 编号完全对应。内环用材料 1，外环用材料 2。

`SPLITR`

- SPLITR 径向细分关键字，用于跟踪模块，在径向方向对几何做虚拟细分，提升积分精度，不会改变真实几何区域数量。
- `1`
- `4`
- 合起来：径向方向分割参数，把每个真实径向区域再切分为 4 条子径向微区，用于 SYBILT 跟踪时的数值积分。

> SPLITR 只影响跟踪积分，不改变 MIX 分配，物理区域仍然是 2 个。

`;`

- GEO: 模块输入数据段结束，分号代表几何定义结束。

> 总结：这个几何是 1 维径向圆柱，圆心 0，外半径 1cm，中间 0.19653cm 分界；内环材料 1，外环材料 2；外径向边界反射；径向跟踪细分 4 份。

### 三、*跟踪：SYBILT，适合 1D / 简单 2D* 这一段

字段速记：

- **SYBILT**：DRAGON 的跟踪模块，专门用于一维、简单二维环形 / 笛卡尔几何，计算积分线。
- **TITLE**：算例标题字符串。
- **EDIT**：输出编辑选项。
- **MAXR**：最大射线跟踪段数。
- **QUA1**：一维角度求积阶数。

#### 这段的作用

All in all：

**这段作用是对 ANGEO 几何执行 SYBILT 射线跟踪，输出对象 TRACK，类型 TRACKING 跟踪对象。**
读取几何对象 ANGEO，生成积分跟踪文件，为后面 ASM 碰撞概率矩阵提供积分数据。

#### 逐行解释

`TRACK := SYBILT: ANGEO ::`

- `TRACK`：输出跟踪数据结构的变量名。
- `:=`：赋值，保存跟踪结果。
- `SYBILT:`：调用 SYBILT 跟踪模块；SYBILT 适合 1D 径向圆柱、简单二维，计算速度快；对比文档 IGE-260 的 NXT 模块，NXT 用于复杂多单元装配几何。
- `ANGEO`：输入依赖，把前面定义好的几何对象传给 SYBILT 模块。
- `::`：SYBILT 模块参数段开始。

`TITLE 'TCM01 minimal'`

- `TITLE`：定义本跟踪算例的标题字符串，会写入输出、二进制跟踪文件，方便识别算例。

`EDIT 1 MAXR 5 QUA1 5 ;`

- `EDIT 1`：编辑输出等级，1 = 基础输出，打印跟踪基本信息；
- `MAXR 5`：跟踪单条射线允许的最大分段数量，1D 几何取小值即可；
- `QUA1 5`：一维角度求积阶数，5 个求积角度，控制角度离散精度；
- `;`：SYBILT 模块输入结束。

> 注意：SYBILT 不需要 NXT 模块那种多级单元装配，直接接收 TUBE 一维几何。输出 TRACK 对象保存所有积分线、区域体积表面积、角度求积信息。

### 四、*ASM：生成碰撞概率 / 响应矩阵* 这一段

#### 这段的作用

All in all：

**这段作用：ASM 模块利用宏观截面 MACRO 和跟踪对象 TRACK，计算多群碰撞概率矩阵 Pij，输出对象 SYS，SYS 是中子输运系统矩阵对象。**
ASM 是 DRAGON 核心模块，根据跟踪得到的几何路径，结合宏观截面，组装碰撞概率矩阵，是碰撞概率法的核心步骤。

#### 逐行解释

`SYS := ASM: MACRO TRACK ;`

- `SYS`：输出系统矩阵对象名字。
- `ASM:`：调用 ASM 组装模块；
- `MACRO`：输入依赖，传入宏观截面库；
- `TRACK`：输入依赖，传入跟踪得到的积分线数据；
- `;`：ASM 模块无额外卡片，直接结束。

> ASM 输入逻辑：几何跟踪给出每一条射线穿过各个区域的弦长；MACRO 给出每个区域的宏观截面；ASM 结合两者计算群内、群间碰撞概率 P (i→j)，存放在 SYS 对象。

### 五、*FLU：解通量，TYPE K 求 Keff* 这一段

字段速记：

- **TYPE K**：本征值 k 计算模式，求解 keff 特征值问题。

#### 这段的作用

All in all：

**FLU 模块读取 SYS 碰撞概率矩阵 + MACRO 截面 + TRACK 跟踪数据，进行中子本征值求解，输出 FLUX 通量对象，包含各区域各能群通量、keff 本征值。**

#### 逐行解释

`FLUX := FLU: SYS MACRO TRACK ::`

- `FLUX`：输出通量求解结果对象名。
- `FLU:`：通量求解模块，碰撞概率法求解中子输运方程；
- `SYS`：输入，ASM 生成的碰撞概率系统矩阵；
- `MACRO`：输入宏观截面；
- `TRACK`：输入跟踪对象；
- `::`：FLU 模块参数段开始。

`TYPE K ;`

- `TYPE K`：指定求解类型为 K 本征值，计算有效增殖系数 keff；
- `;`：FLU 模块参数结束。

> 除 TYPE K 之外还可以用 TYPE FIX 源驱动固定源计算。求解完成 FLUX 对象保存：各区域各能群中子通量、keff、裂变源分布。

### 六、*EDI：编辑 / 均匀化 / 凝聚，SAVE 保存* 这一段

#### 这段的作用

All in all：

**EDI 编辑模块，读取前面 MACRO、TRACK、FLUX 结果，做结果输出、打印、存储，输出对象 EDITION。SAVE 把全部对象保存到二进制结果库。**

#### 逐行解释

`EDITION := EDI: MACRO TRACK FLUX ::`

- `EDITION`：输出编辑对象名。
- `EDI:`：编辑输出模块，DRAGON 用来打印、保存、均匀化、能群凝聚；
- `MACRO TRACK FLUX`：依赖输入，截面、跟踪、通量结果；
- `::`：EDI 参数段开始。

`EDIT 3 SAVE ;`

- `EDIT 3`：输出等级 3，详细打印输出，打印区域通量、keff、截面信息；
- `SAVE`：关键字，把 MACRO、TRACK、FLUX 全部数据保存进 DRAGON 二进制结果库，后续可以重新读取；
- `;`：EDI 模块结束。

---

### 七、*清理和结束* 这一段

#### 这段的作用

All in all：

DELETE 模块删除内存中已经不需要的数据对象，释放内存，END 结束整个 DRAGON 输入算例。

#### 逐行解释

`FLUX SYS TRACK := DELETE: FLUX SYS TRACK ;`

- `DELETE:`：DRAGON 内存释放模块。
- 把 FLUX、SYS、TRACK 这几个大对象从内存删除；MACRO 和 EDITION 一般不删除，方便输出；
- `:=`：左侧是要删除的对象列表。

`END: ;`

- `END:`：DRAGON 输入文件结束关键字，整个算例到此结束。

> 整体链路总结：
> MAC (截面) → GEO (几何) → SYBILT (跟踪) → ASM (组装碰撞概率) → FLU (求解 keff 通量) → EDI (打印保存) → DELETE 释放内存 → END 结束。
> 本算例对应 IGE-260 报告之外的 SYBILT 跟踪路径：SYBILT 专门处理简单 1D/2D，NXT 模块处理复杂多级装配几何。

## 标准模块调用顺序

- 宏观截面路线

```text
MAC:  ->  GEO:  ->  SYBILT:/EXCELT:/NXT:  ->  ASM:  ->  FLU:  ->  EDI:
```

- 微观截面路线

