## DONJON

DONJON 本身比较简单：CLE-2000 在 DRAGON 那块已经学得差不多了，DONJON 剩下的只是学模块，用到哪个学哪个就行。

这个文件夹不是教程，是**这个课题每个阶段干了什么**的记录。代码在上一级目录（[../README.md](../README.md)），这里只放实验过程、结论和当时的原始数据。

### 一、这个课题在做什么

CANDU-6 重水堆是不停堆连续换料的：每隔一段时间要把 4 根烧得差不多的燃料通道换成新的。换哪 4 根，直接影响堆芯的增殖能力（Keff）和功率分布（PPF）。本课题就是用 **PSO 搜索 + BP 神经网络代理模型打分 + DONJON 真实物理校验**，把 360 天（180 步）的换料序列自动优化出来。

### 五、当时踩过的坑（留给后面的人）

1. DONJON 对输入卡格式极度挑剔，手写 `.c2m` 放 `data/` 下面各种报错，最后改成在 Python 里拼整张 x2m 才通。
2. 基准题里写死了 `ASSERTS`：Keff 不等于 0.9962499 就直接 Abort，改换料序列必须先注释掉。
3. 通道名不能自己编（`REFUEL CHAN` 只认算例里给的名字），而且**只能选真正装了燃料的通道**，否则直接算崩。
4. 每次运行只留一个 `Candu6.result`，历史结果必须自己写 csv，不能靠堆文件。
